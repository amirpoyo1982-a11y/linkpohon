# linkpohon

## Custom wallpaper

In Panel Admin > Tetapan, choose the wallpaper type and paste a direct HTTPS media URL. Auto detects MP4/WebM links; choose Video explicitly for extensionless video URLs. Images and animated GIF/WebP remain supported. Use Pratonton, adjust the dimming slider, then Simpan Tetapan to publish through the existing Firebase settings. OFF uses the original theme without deleting the saved URL. YouTube and webpage URLs are not direct video media. Videos loop muted, pause in hidden tabs, and preview videos are cleaned up when the admin panel closes.
